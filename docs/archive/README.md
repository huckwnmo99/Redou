# Archive (보관)

현행이 아닌 문서를 **이력 보존용**으로 모은 곳. ⚠️ **여기 내용은 최신 상태가 아니다** — 현행은 [`../README.md`](../README.md)와 [`../harness/`](../harness/)를 본다.

- `features/` — 구현 완료된 fix/new 계획서 (작성 당시 기록)
- `proposals/` — 옛 통합·아키텍처 제안서 (2026-04~05)
- `legacy/` — 옛 numbered 구조 (01-Idea, 02-database, 03-frontend, 04-planning)
- `ROADMAP.md` — stale(2026-04). 현행 상태는 `../harness/main/feature-status.md`
- `PROJECT_STRUCTURE.md` — 레거시. 현행은 `../harness/main/overview.md`
- `RECOMMENDED_SUBAGENTS.md` — 현 Codex-only 규칙 이전 문서

> 보관 문서 내부의 상대 링크는 작성 당시 경로라 깨질 수 있다(이력 보존이 목적). 정리 경위는 `../tasks/docs-cleanup/`.
